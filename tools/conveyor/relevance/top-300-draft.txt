# Robonyx model-library relevance list, top 300 (DRAFT, needs Hugh's sign-off)
#
# STATUS: DRAFT. Nothing here is authorised. Hugh signs off the composition, and only then
# does the nightly loop select from it. Rename to top-300.txt on sign-off.
# 300 is the target size; this draft carries 274 entries, so there is room for whatever
# sign-off adds. The exact count is printed at the end of the file.
#
# WHY: high-stock LCSC ordering (preferred DESC, stock DESC) selects for assembly-house
# popularity, not for what a person simulating a circuit reaches for. Batches 1 to 9
# harvested the catalog head and yielded roughly 230 promotable models a day; by the
# batch-16 cycle the same selection was yielding around 3 a day because the head was gone
# and the tail is neither relevant nor well documented. This list replaces catalog rank
# with curated relevance.
#
# SOURCES for this draft:
#   1. parts already in packages/model-library/models, so the list states the target
#      composition rather than only the gap. Lines marked "in library" are skipped by
#      select as identity collisions, and the skip report becomes the coverage report.
#   2. the jellybeans a hobbyist or student actually meets: LTspice standard.dio /
#      standard.bjt / standard.mos membership, KiCad symbol-library staples, the ngspice
#      distributed examples, and the Arduino and Falstad ecosystem parts.
#
# FORMAT: one MPN per line.
#
#   MPN | manufacturer | priority | family
#
# Fields after the MPN are optional; separate them with "|" (never a comma, because
# ordering codes contain commas, as in PMBT2222A,215). Blank manufacturer means "let the
# catalog pick the best stocked row". Priority is an integer, lower first, default 100:
#   1 = core teaching part, 2 = common shop part, 3 = long tail.
# Family is diode, bjt, or mosfet and overrides catalog classification.
# "#" starts a comment, inline comments allowed.
#
# OPEN QUESTIONS FOR SIGN-OFF are recorded at the end of this file.

# OPEN QUESTIONS FOR SIGN-OFF
#
# 1. Depth versus breadth. This draft spends about a third of its lines on parts already
#    in the library so the file states the whole target. Say the word and those lines are
#    dropped, making the list a pure work queue of roughly 200 new parts.
# 2. Family scope. The conveyor fits diode, bjt and mosfet only. JFETs (J111, 2N5457,
#    BF245), IGBTs, and voltage references (TL431) are deliberately absent and need new
#    archetypes before they can be listed.
# 3. Priority meaning. Priority currently orders selection only. It could also drive the
#    nightly budget, for example priority 1 parts get the retry and priority 3 parts do not.
# 4. Manufacturer pinning. Every line leaves the manufacturer blank, so the best stocked
#    catalog row wins. Generic MPNs (M7, SS14, S8050) resolve to whichever second-source
#    vendor LCSC stocks best, which may not be the vendor whose datasheet you want cited.
# 5. Ordering-code variants. 1N4148 versus 1N4148W versus 1N4148WS are genuinely different
#    packages with different datasheets, and all three are listed. Confirm that is wanted
#    rather than one entry per die.

# 274 entries; 100 already represented in the reviewed library, 174 would be new work.
