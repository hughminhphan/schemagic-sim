## Narrow correction

Consecutive sealed cohorts may be combined for one fit pass only when all of the following are true:

1. they are adjacent ranges from the same frozen source manifest and the same component family;
2. each used fresh PDFs and Terra responses under the current recovery contract;
3. every response, job, topology disposition, repair count, and completion-ledger hash is sealed;
4. neither cohort has run a fit or promoted a package;
5. the aggregate retains every original denominator row, topology park, and evidence failure with zero substitutions;
6. only candidates already accepted by the pure evidence validator enter fitting; no response is edited, repaired again, reclassified, or regenerated; and
7. the aggregate receives exactly one `--no-park` fit pass and zero retries.

The original terminal prefit records remain accurate for their isolated 40-row windows. This addendum supersedes only their prohibition on later use as one content-addressed adjacent aggregate.
