# scheMAGIC v0.2.0-rc.1

**Release date:** 2026-08-30
**Status:** pre-1.0 release candidate

This release consolidates the previously separate Component Library, Simulator/Editor, Measurement Workbench and Motor/Power Designer work into one versioned application. The public static app exposes the Simulator at `/` and the Designer at `/designer`.

## Promotion status

Promotion is paused on the preserved `codex/v0.2.0-rc.1-integration` branch. No `v0.2.0-rc.1` tag or GitHub release exists, `main` has not been advanced, and the production Cloudflare Pages deployment remains unchanged.

At integration commit `7acfca5`, GitHub Actions run `33315775295` passed the complete 93-case browser integration suite, the native/WebAssembly comparison gate, and the bounded Designer runtime/heap audit. The workspace gate remains red because two deterministic generation tests exceeded their individual shared-runner ceilings:

- Design Export's ordinary-artifact preservation test exceeded 60 seconds and also reached Vitest's worker update timeout.
- Motor Designer V2's strict/permissive direct-gate compatibility test exceeded 30 seconds.

The same affected Design Export and Motor suites pass locally under Node 22 with one worker (15/15 in 45.28 seconds and 28/28 in 91.59 seconds respectively). The web workspace passed 117/117 tests in the final hosted run after the exact MIC4606 generation ceiling was corrected. These results indicate environment-sensitive test duration, but the failed hosted workspace gate remains a hard promotion block; it is not reclassified or waived. The bounded overnight release session stopped without another retry.

## Persisted-format compatibility

- Simulator V1 and legacy flat V2 documents migrate to the current Simulator V3 format.
- Designer multi-circuit documents use V4. V4 owns design blocks, circuits, scenarios and a default circuit identifier.
- Parsers reject ambiguous or invalid shapes instead of interpreting two incompatible contracts as the same version.
- Simulation outputs carry both deterministic execution-receipt evidence and Measurement run/scheduling provenance.

## Verification contract

The exact release tree is accepted only after a clean install and the following layers pass:

1. Workspace unit tests, type checks and production builds.
2. Validation of all 771 component-model package structures and evidence contracts.
3. Component-schema, model-library, model-factory and conveyor suites.
4. Pinned native ngspice-46/WebAssembly reference fixtures and application goldens.
5. Browser integration for Simulator, Measurement and Designer, including bounded accessibility and offline checks.
6. A content-addressed Designer runtime contract with a 10-second cold shared-runner p95 ceiling, retained-heap and long-task limits.
7. Repository release scan and Designer release-audit report.

The 2026-08-30 local Chromium diagnostic passed with Motor p95 4.1998 seconds, Power p95 1.3380 seconds, and report hash `sha256:c1a0c94b5f57a7d852ef85b325b247c15506124de1bad1f6fc3797dc8d38ad6f`. These numbers are environment-bound diagnostics, not deployed-performance evidence.

A GitHub prerelease and Cloudflare deployment will be created only after the hosted workspace gate passes. Until then, this document records the exact promotion blocker and preserved recovery points.

## Known limitations and exceptions

- `ti/LM311`, `ti/LM393` and `ti/TLV3702` have inherited recorded failures for the `supply_current.cir` native/WebAssembly comparison. These predate the 61 strict additions in this release.
- `MCP6002` and `MCP6004` intentionally keep their noise benches native-only.
- The repository does not yet freshly replay every electrical bench across all 771 packages in one release command. Structural/evidence validation covers all packages; bounded native/WASM gates cover the promoted strict benches and release fixtures.
- Manual assistive-technology review, deployed offline/cache behavior, authenticated runtime evidence, external KiCad verification and KiCad GUI open-without-repair remain external gates. The audit is not weakened to hide these blockers.
- Designer exports do not claim PCB layout, footprint completeness, thermal proof, safety compliance, provider availability or production release authority.
